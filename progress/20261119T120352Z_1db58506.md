# 2026-11-19, feature session (#61: conflict analysis with backjumping)

- New search `cdcl` (end of `core/src/lib.rs`); `solve` calls it, and the old `search` stays as
  its fallback. It keeps the recursive shape of `search` (one call per propagation step or
  decision) and adds:
  - a decision level `d`;
  - per atom: its level `lv`, a time stamp `ts`, and a reason `rs` (0 none / decision, 1 closure,
    `2 + i` a problem or learned clause);
  - a third result `j`. Without a model, `j >= d` means the branch is refuted (the old claim
    `¬ pext t f`), and `j < d` means "jump back to level `j`", which claims nothing.
- A conflict (a falsified clause, or a closure conflict with its explanation clause) is analysed
  (`analyze`): 1UIP resolution with the reasons of the atoms at level `d`, latest stamp first.
  - Closure reasons are computed lazily (`theory_reason`): `path_explain` on the atoms set true
    before the atom, confirmed by `rows_join`, otherwise a tautology.
  - Closure-set false atoms have no reason.
  - The learned clause is appended. With exactly one atom at level `d` it returns a jump to the
    highest other level; otherwise it reports the branch refuted (chronological).
- The decision frame at level `d` handles a jump to `d`: the last learned clause is unit there,
  so it is propagated (reason: that clause).
  - If the clause is instead false, the branch is refuted.
  - If it is neither (should not happen), the frame falls back to the complete `search`.
  - A refuted `k = true` branch continues with `k = false` as before.
- Why recursion and not a loop with a trail: the jump result costs almost no proof. Frames
  between the conflict and the target return the jump unchanged and claim nothing. Every claim
  (`¬ pext`) still comes from a conflict at the frame's own assignment. Termination is the old
  fuel argument (each call sets an atom).

- What NEQ/PEQ need next (follow-up issues):

     changes, check conflicts and separations against it without a new closure;
  2. cheaper closure reasons: keep the merge log of the last closure instead of rebuilding it
     for every resolved atom;
  3. then a dynamic decision order.
