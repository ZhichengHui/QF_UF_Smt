## Notes for a lessons session

- A task heap built by `isabelle_build_heap` from `dev/` goes stale as soon as any `.thy` file in
  `dev/` changes, even one outside the heap's session, and `isabelle-devcopy` rewrites `dev/`. Build
  the heap from a separate directory that holds copies of only the theories it contains
  (`target/heapsrc/` here).
- Inside a method expression, sequence methods with `,`: `(rule r; assumption?) simp` is an
  outer-syntax error ("end-of-input expected"). Only `by m1 m2` takes two methods without a comma.
- Speed-only mutants of the watch lists and the closure can be caught by a test when the missed
  conflict survives to the leaves: the leaf refutes without a learned clause, and free atoms
  decided after it make the search exponential.
